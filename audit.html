Audit Methodology

How each score is calculated.

  • Satisfaction = average valid rating ÷ 5 × 100
  • Recommendation = positive recommendation responses ÷ valid recommendation responses × 100
  • Future Interest = positive future-interest responses ÷ valid responses × 100
  • Repeat Intent = positive repeat-intent responses ÷ valid responses × 100
  • Interest/Hold = positive held-interest responses ÷ valid held-interest responses × 100
  • Presentation = weighted positive presentation responses ÷ valid presentation responses × 100
  • Emotional Response = positive emotional responses ÷ valid emotional responses × 100
  • Health Score = weighted sum of the four primary metrics (rating, recommendation, future interest, repeat intent) using configured weights
  • Growth = current period value − previous equivalent period value (percentage-point change)
  • Confidence = based on sample size and completeness, using configured thresholds
  • All metrics recalculate automatically on data change, filter change or settings change.
